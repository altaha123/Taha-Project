# Bundled fonts

`InstrumentSerif-Regular.ttf` and `IBMPlexMono-{Regular,Medium}.ttf` are the
site's own typefaces, bundled so that a server-rendered share card looks like
the product rather than like a generic template.

Both families are released under the **SIL Open Font License 1.1**, which
permits redistribution as part of a larger work. Sourced from Google Fonts.

- Instrument Serif — https://fonts.google.com/specimen/Instrument+Serif
- IBM Plex Mono — https://fonts.google.com/specimen/IBM+Plex+Mono
